# ArchitectMentor AI tutorial series

Published in PL and EN, one tutorial per week. First tutorial: 2026-10-02. Next release: 2026-10-09.

Purpose: teach architects to use AI to clarify, compare, challenge and verify decisions. The architect owns the decision. Each tutorial follows: explicit learning goal, anonymised or model brief, reusable prompt, clearly labelled example output, architect review, revised mechanism, evidence or test, learner task, primary sources and related tools. Never invent firsthand experience, model transcripts or deployment outcomes. Disclose AI assistance. Do not publish confidential briefs.

Register paired articles in articles.ts/articles-en.ts under architektura-it-ai/architecture-with-ai, update editions and both homepages, verify reciprocal language links, RSS, sitemap and comments. Keep planned lessons clearly distinguished from published ones. Verify diagrams against the production Mermaid version; syntax success is separate from architectural correctness.

HLD models: default gpt-4.1; optional gpt-4.1-mini and gpt-6.1-sol. Sol uses Responses reasoning.effort low without temperature; its output budget includes reasoning. Model choice does not certify the architecture. Add no automatic paid second review or repair without a bounded design and explicit scope.

Next topics: questions before design; alternatives and trade-offs; reviewing dependencies; drafting an ADR. Pick one learning goal per lesson.
